## 🚀 Projects

### Day 01 — Daily ETL File Validation

A Python-based file validation program that checks incoming ETL files before processing.

The project validates:

* Record count
* Expected record count
* File size
* File type
* Source system
* Processing status

### Example

```text
========================================
        DAILY FILE VALIDATION
========================================

Environment   : PROD
File          : customer_YYYYMMDD.csv
Source        : ORACLE
File Type     : CSV
Records       : 125000
Expected      : 120000
File Size     : 85 MB
Status        : SUCCESS
Message       : File validation successful

========================================
```
